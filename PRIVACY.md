# sona-sync Privacy Policy

Last updated: November 7, 2026

sona-sync is a personal script used only by its developer, Jin Yu. It is not offered to the public.

## What it accesses

Google Calendar: reads and edits events on the developer's own research-team calendar to add or remove study session events.

Gmail (send only): sends notification emails from the developer's own Gmail account to the developer's own work inbox. It cannot read any email.

## How data is handled

All processing happens locally on the developer's own computer. No data is sent to any server other than Google's APIs. No data is sold, shared, or used for advertising. Sign-in tokens are stored only on the developer's computer.

Access can be revoked at any time at https://myaccount.google.com/permissions
